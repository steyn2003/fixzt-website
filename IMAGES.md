## Image Guidelines

1. **Format**: Use modern formats (WebP, AVIF) for better performance, with JPG/PNG fallbacks
2. **Optimization**: Compress images before uploading (use tools like TinyPNG, Squoosh)
3. **Quality**: Use high-quality, professional images that reflect the brand
4. **Consistency**: Maintain consistent style and color grading across all images
5. **Alt Text**: Add appropriate alt text for accessibility

## How to Add Images

1. Place your images in the `/public` folder
2. Name them exactly as shown above (e.g., `property-1.jpg`, `service-sales.jpg`)
3. The website will automatically display them in place of the emoji placeholders
